# IDAD-TP2

This repository contains Cookie Club, a cookie-clicker game built with Vue 3, Vuex, and Vue Router.

## Run the game

```sh
cd cookie-exercises
npm install
npm run dev
```

Vite prints the local application URL in the terminal.

Full documentation is available in [cookie-exercises/README.md](cookie-exercises/README.md), including features, the demo administrator account, build commands, and local-storage limitations.
